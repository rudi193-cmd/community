## Why this exists

AI is entering K-12 classrooms faster than lesson plans are being written for it.

Teachers are figuring this out in isolation — one classroom at a time, with no shared place to put what they learn.

This repo is that place. Fork it, add your lesson, send a pull request. Or email us your lesson and we will add it for you.

No GitHub experience required. If you can edit a text file, you can contribute.

## How to Contribute

### Option A — GitHub (5 minutes)
1. Fork this repo
2. Copy `lesson-template.md`
3. Fill it in and save it in `/lessons` as `subject-graderange-your-title.md`
4. Open a pull request — we review within 48 hours

### Option B — Email (no GitHub needed)
Send your lesson to admin@emergingrule.com with subject `[Community Lesson]`.
We will add it and credit you as contributor.

### What we need most right now
- Science lesson for grades 3-5
- Social Studies or History lesson for middle school
- Computer Science or coding lesson (any grade)
- Spanish-only version of El Jardin de Numeros
