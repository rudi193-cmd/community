# Emerging Rule Community

An open knowledge base for K-12 educators, researchers, and builders
working at the intersection of AI and education.

Built by and for the community around LevelShip and Emerging Rule.
https://www.emergingrule.com

## What lives here

- AI-powered lesson ideas organized by grade and domain
- Bilingual resources in English and Spanish
- LevelShip skill taxonomy contributions
- Educator workshop notes and templates
- Research references and reading lists
- Community project showcases

## How to contribute

1. Fork this repository
2. Add your contribution in the right folder
3. Open a pull request with a one-line description
4. We review and merge within 48 hours

No coding experience required.
If you can edit a text file, you can contribute.
