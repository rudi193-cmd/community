# Contributing to Emerging Rule Community

Welcome! This is an open knowledge base for K-12 educators, researchers, and builders working at the intersection of AI and education. **No coding experience required.**

If you can edit a text file, you can contribute.

---

## What We're Looking For

- ✅ AI-powered lesson ideas (any grade, any subject)
- ✅ Bilingual resources (English/Spanish especially welcome)
- ✅ LevelShip skill taxonomy additions
- ✅ Educator workshop notes and templates
- ✅ Research references and reading lists
- ✅ Project showcases and case studies

---

## How to Contribute a Lesson (Step by Step)

### Option A — Via GitHub (preferred)

1. **Fork** this repository (click "Fork" in the top right)
2. Copy `lesson-template.md` from the root folder
3. Fill it in with your lesson
4. Save it in the `/lessons` folder with this naming format:
   ```
   subject-graderange-short-title.md
   ```
   Example: `math-3-5-ai-story-problem-factory.md`
5. Open a **Pull Request** with a one-line description
6. We review and merge within 48 hours

### Option B — Via Email

Not comfortable with GitHub yet? Email your lesson to **admin@emergingrule.com** with the subject line `[Community Lesson]` and we'll add it for you and credit you as contributor.

Use `lesson-template.md` as your starting point. Key fields:

| Field | Required? |
|---|---|
| Grade Level | ✅ |
| Subject | ✅ |
| Language (English/Spanish/Bilingual) | ✅ |
| AI Tool Used | ✅ |
| Objective | ✅ |
| Lesson Plan | ✅ |
| At least one sample AI prompt | ✅ |

| Differentiation notes | Optional |

## Good First Contributions

New here? Look for issues labeled **`good first issue`** — these are specific, well-scoped tasks that are perfect for first-time contributors.

Some easy ways to start:
- Translate an existing English lesson to Spanish
- Add a lesson in a subject/grade we're missing
- Fix a typo or formatting issue
- Add a research reference to the reading list
