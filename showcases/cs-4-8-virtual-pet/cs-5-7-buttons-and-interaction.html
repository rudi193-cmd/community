Buttons and Interaction

How do you make a program do something when you click?

How do you make a program do something when you click?

Every button on every website follows the same basic idea: you click, something runs, something changes. Once you understand that pattern, you can wire up almost anything.

The HTML button

A button in HTML looks like this:

<button onclick="feed()">🍎 Feed</button>

The onclick attribute tells the browser: "when this button is clicked, call the function named feed." That's it. The button doesn't do anything on its own — it just hands control over to your JavaScript.

The function that runs

When the button is clicked, this function runs:

function feed() {
  food = Math.min(100, food + 20); // add 20, but never go above 100
  happy = Math.min(100, happy + 5); // feeding makes them a little happy too
  updateDisplay(); // show the new numbers
}

Why Math.min(100, food + 20)?

Without the cap, clicking Feed ten times would push food to 280 — which doesn't mean anything. Math.min(100, food + 20) says: "take whichever is smaller — 100, or food + 20." The result can never exceed 100.

Same idea for the other direction: Math.max(0, energy - 10) means energy can never go below zero.

Every button follows the same pattern: onclick calls a function, the function changes a variable, the function updates the display. Three steps, every time.

Multi-stat actions

Playing is more interesting than feeding, because it changes two things at once — and they go in opposite directions:

function play() {
  happy = Math.min(100, happy + 15); // playing feels good
  energy = Math.max(0, energy - 10); // but it costs energy
  updateDisplay();
}
Playing costs energy. Actions that affect multiple stats make your pet feel like a real system — things connect. You can't just spam Play forever, because eventually your creature runs out of energy.

Making the creature react visually

Changing a number is invisible. You need the drawing code to look at the numbers and respond:

// In the draw loop, check happy every frame:
if (happy > 80) {
  // make the creature bounce
  bounceY = Math.abs(Math.sin(t * 3)) * -12;
} else {
  bounceY = 0;
}

That if block lives inside the animation loop — it runs 60 times per second. So the moment happy crosses 80, the bounce starts. The moment it drops below 80, the bounce stops. The state drives the visuals automatically.

You can do the same for droopy eyes when a stat is low:

if (food < 20 || energy < 20 || happy < 20) {
  // draw half-closed eyes instead of normal eyes
  eyeH = 3; // squish the eye height
} else {
  eyeH = 10; // normal open eyes
}

Now your buttons don't just change numbers — they change how the creature looks. That's what makes a program feel alive.

Build your own button

// your button's code will appear here
function feed() {
  food = Math.min(100, food + 20);
  happy = Math.min(100, happy + 5);
  spawnParticles('🍎', 3);
  updateBars();
}

function play() {
  happy = Math.min(100, happy + 15);
  energy = Math.max(0, energy - 10);
  spawnParticles('✨', 4);
  updateBars();
}

function rest() {
  energy = Math.min(100, energy + 25);
  updateBars();
}

// In the draw loop:
if (happy > 75) {
  bounceY = Math.abs(Math.sin(t * 3)) * -12;
}
if (food < 20 || energy < 20 || happy < 20) {
  eyeH = 3; // droopy
}
