Buttons & Interaction

How do you make a program do something when you click?

Tap a button → code runs → your creature reacts.
click me!

Every button on every website follows the same idea: you click, something runs, something changes. Learn that one pattern and you can wire up almost anything.

A

The HTML button

A button in HTML looks like this:

pet.htmlHTML
<button onclick="feed()">🍎 Feed</button>

The onclick attribute tells the browser: "when this button is clicked, call the function named feed." That's it. The button doesn't do anything on its own — it hands control over to your JavaScript.

B

The function that runs

When the button is clicked, this function runs:

pet.jsJavaScript
function feed() {
  food  = Math.min(100, food + 20);  // add 20, but never above 100
  happy = Math.min(100, happy + 5);   // feeding makes them a bit happy too
  updateDisplay();                    // show the new numbers
}
C

Why Math.min(100, …)?

Without the cap, clicking Feed ten times would push food to 280 — which doesn't mean anything. Math.min(100, food + 20) says: "take whichever is smaller — 100, or food + 20." The result can never go over 100.

Same idea the other direction: Math.max(0, energy - 10) means energy can never drop below zero.

Every button is the same three steps. onclick calls a function → the function changes a variable → the function updates the display. Every time.
D

Actions with a cost

Playing is more interesting than feeding, because it changes two things at once — and they go in opposite directions:

pet.jsJavaScript
function play() {
  happy  = Math.min(100, happy + 15);  // playing feels good
  energy = Math.max(0,   energy - 10); // but it costs energy
  updateDisplay();
}
Playing costs energy. Actions that touch more than one stat make your pet feel like a real system — things connect. You can't just spam Play forever, because eventually your creature runs out of energy.
E

Make the creature react

Changing a number is invisible. The drawing code has to look at the numbers and respond:

pet.jsdraw loop
// inside the draw loop, check happy every frame:
if (happy > 80) {
  // make the creature bounce
  bounceY = Math.abs(Math.sin(t * 3)) * -12;
} else {
  bounceY = 0;
}

That if block lives inside the animation loop — it runs 60 times per second. The moment happy crosses 80, the bounce starts. The moment it drops below, the bounce stops. The state drives the visuals automatically.

?

What would happen if food was at 95 and you clicked Feed, without the Math.min? Picture the bar.

Now your buttons don't just change numbers — they change how the creature looks. That's what makes a program feel alive. Ready to wire one up yourself?
