How do you tell a computer to draw something?

How do you tell a computer to draw something?

When you use a drawing app, someone wrote code that told the computer exactly which pixels to color, and in what order. Today you're going to write that code yourself — and the thing you'll draw is a living, moving pet.

What HTML is

An HTML file is just a text file — but a special kind. When your browser opens it, it reads the instructions inside and builds what you see on screen. That's it. No magic.

The file has two parts: a head (invisible setup, like the title) and a body (everything you actually see). Inside the body, you put elements — tags that describe what should appear.

<!DOCTYPE html> <html> <head> <title>My Pet</title> </head> <body> <!-- everything visible goes here --> <canvas id="c" width="300" height="220"></canvas> <script> // drawing code goes here </script> </body> </html>

The canvas: your pet's home

The <canvas> element is like a blank whiteboard inside your browser. By itself it shows nothing. But once you connect it to JavaScript, you can draw any shape you want — circles, rectangles, text, gradients — one line of code at a time.

To start drawing, you ask the canvas for its "2D context" — think of it as picking up a paintbrush:

const canvas = document.getElementById("c"); const ctx = canvas.getContext("2d"); // ctx = your paintbrush

Now you can draw a circle using ctx.arc. Arc takes a center point (x, y), a radius, a start angle, and an end angle. A full circle goes from 0 to 2π:

// Draw the body — a circle at center (150, 110), radius 50 ctx.beginPath(); ctx.arc(150, 110, 50, 0, Math.PI * 2); ctx.fillStyle = "#6c63ff"; ctx.fill();

Draw order: last goes on top

The canvas draws like a painter — whatever you put down later appears on top of whatever was there before. So if you draw the body first and then draw the eyes, the eyes sit on top of the body. If you did it backwards, the body would cover the eyes.

The canvas draws in order. Whatever you draw last goes on top.

Here's how you draw the body and then add two eyes on top:

// 1. Body first ctx.beginPath(); ctx.arc(150, 110, 50, 0, Math.PI * 2); ctx.fillStyle = "#6c63ff"; ctx.fill(); // 2. Eyes on top — drawn after, so they appear in front [-18, 18].forEach(function(offset) { ctx.beginPath(); ctx.arc(150 + offset, 100, 8, 0, Math.PI * 2); ctx.fillStyle = "white"; ctx.fill(); });

Making it move: requestAnimationFrame

A single drawing is just a picture. To make it animate, you need to clear the canvas and redraw it over and over — so fast that your eye sees smooth motion, not individual frames.

The browser has a built-in tool for exactly this: requestAnimationFrame. You give it a function to call, and the browser calls that function right before it paints the next screen — about 60 times every second.

requestAnimationFrame calls your draw function ~60 times per second. That's animation.

Here's the full animation loop. The pet moves left and right and bounces off the walls:

let x = 150; // starting position let dx = 2; // speed: pixels moved per frame function draw() { // clear the whole canvas before redrawing ctx.clearRect(0, 0, canvas.width, canvas.height); // draw body at current x ctx.beginPath(); ctx.arc(x, 110, 50, 0, Math.PI * 2); ctx.fillStyle = "#6c63ff"; ctx.fill(); // move x, bounce off left and right walls x += dx; if (x > canvas.width - 50 || x < 50) dx = -dx; // ask the browser to call draw() again next frame requestAnimationFrame(draw); } draw(); // kick it off

That's really it. Three ideas — draw in order, clear and redraw, ask for the next frame — and you have animation.
